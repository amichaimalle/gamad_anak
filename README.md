# גמד ענק – משפחת מלא-מלאך-מלמד

אפליקציית ווב (Next.js) לניהול משחק גמד ענק, מותאמת לטלפון.

## הרצה מקומית

```bash
npm install
npm run dev          # http://localhost:3000
npm run dev:phone    # פתוח גם לטלפון באותה רשת WiFi: http://<IP של המחשב>:3000
npm test             # בדיקות ההגרלה והמשחק
```

מקומית הנתונים נשמרים בקובץ `data/db.json` (מחיקה שלו = התחלה מאפס).

- קוד מנהל: `308476977`
- קודי משתתפים: 5 ספרות, נוצרים בהגרלה.

## העלאה ל-Vercel (חינמי)

ב-Vercel אין דיסק קבוע, לכן צריך מסד נתונים קטן:

1. מעלים את הפרויקט ל-GitHub ומייבאים ב-Vercel (New Project).
2. בפרויקט ב-Vercel: **Storage → Create → Upstash (Redis)**, תוכנית Free, ומחברים לפרויקט.
   זה מוסיף אוטומטית את `KV_REST_API_URL` ו-`KV_REST_API_TOKEN`.
3. Redeploy. זהו.

## איך זה עובד

- `lib/draw.js` – ההגרלה: אף אחד לא מקבל את עצמו, את מי שאסור לו, ואין זוג הדדי (א' גמד של ב' וגם ב' גמד של א'). אחרי כל הגרלה יש בדיקת תקינות לפני שמירה.
- `lib/game.js` – מצב המשחק. השידוכים נשמרים בנפרד ולא נשלחים אף פעם למסך המנהל.
- `app/` – המסכים (כניסה, מסך אישי, ניהול) וה-API.
